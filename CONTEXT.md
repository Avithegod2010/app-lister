# App Lister — project context

Single-purpose Android app (Expo SDK 54, TypeScript, expo-router) that lists every installed app. Material You design. Owner: Avithegod2010, MIT licensed.

## Domain vocabulary

- **scan** — one pass of `PackageManager.getInstalledPackages` on the native side; emits `onScanProgress {loaded,total}` events; icons cached to `cacheDir/app_icons/<pkg>.png` (128px PNG, reused across scans).
- **installed-apps** — local Expo Modules API module at `modules/installed-apps` (Kotlin: `expo.modules.installedapps.InstalledAppsModule`, native name `InstalledApps`). JS dep: `"installed-apps": "file:./modules/installed-apps"`. API: `getApps()`, `launchApp(pkg)`, `openAppInfo(pkg)`, `getWallpaperColor()`.
- **source color** — wallpaper primary color used to build M3 tonal palettes; fallback `#6750A4`; persisted in AsyncStorage `app-lister.theme.source`.
- **tokens** — `ThemeTokens` (src/theme/tokens.ts): M3 roles incl. surfaceContainer tiers; built via `@material/material-color-utilities` `themeFromSourceColor`.

## Structure

- Routes: `app/index.tsx` (list), `app/pkg.tsx` (details, param `pkg` = package name).
- `src/store/apps.tsx` AppsProvider: status loading/ready/error + rescan.
- `src/theme/ThemeProvider.tsx`: mode system/light/dark persisted (`app-lister.theme.mode`), `useTheme()` → {tokens, dark, mode, hydrated, setMode}.
- `usePersistedState` (AsyncStorage) keys: `app-lister.filter|sort|view`.

## Build

- `eas.json`: `preview` profile = APK (internal distribution); `production` = AAB.
- Android package: `com.avithegod2010.applister`. Permission: `QUERY_ALL_PACKAGES` only.
- Requires EAS token (`EXPO_TOKEN`) for `eas init`/`eas build` — never commit it.
- Custom icons generated by `../.applister-icons/gen-icons.js` (sharp) into `assets/images/`.

## Gotchas

- Native module doesn't exist in Expo Go — JS wrapper degrades to no-op with `isNativeAvailable=false`; error screen explains dev build requirement.
- FlashList `numColumns` changes require remount (the list uses `key={view}`).
- After editing app.json run `npx expo prebuild -p android`; committed repo is CNG (no `android/` in git).
